# Atmos Shotgun Tiers

Мод для Factorio 2.1: добавляет **5 уровней улучшения** для выбранного оружия и боеприпасов.

Крафт: **5 предметов предыдущего тира → 1 предмет следующего**. Рецепты тиров доступны с начала игры.

## Покрытые предметы

**Оружие:** дробовик, боевой дробовик, пистолет, пистолет-пулемёт, ракетница

**Патроны:** магазин, бронебойные, урановые, дробовые патроны, бронебойные дробовые, ракеты

## Настройки (startup)

- Бонус урона оружия за тир
- Бонус дальности оружия за тир
- Бонус скорости атаки оружия за тир
- Бонус урона патронов за тир
- Доп. дробинки за тир (целое; по умолчанию +1 за шаг тира)

## Установка

Скопируйте `Atmos-Shotgun-Tiers_2.1.1.zip` в папку `mods` Factorio или скачайте с [Mod Portal](https://mods.factorio.com) после публикации.
